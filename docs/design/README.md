Розмір: **S** — до тижня, **M** — 1–3 тижні, **L** — понад 3 тижні для одного розробника, разом із бекендом, фронтендом, міграціями й тестами.

Рекомендований порядок: 1 → 7 (in-app + email) → 3 → 8 (експорт і імпорт) → 2 → 5 → 4 → 6. Першими йдуть найменші функції, від яких залежать інші. Найбільше відкритих продуктових питань у 4 і 6, тому вони останні.

Спільні правила для всіх функцій, закладені попередніми фазами:
- нові сутності, що належать депо, мають `DepotId` і глобальний фільтр депо;
- редаговані сутності мають `RowVersion` і повертають `409` при конфлікті;
- час зберігається в UTC і показується в часовому поясі локації, а межі днів рахуються в бізнес-часовому поясі (Europe/Kyiv);
- нові значення enum додаються лише в кінець;
- повідомлення API — у ресурсах uk/en;
- ендпоінти — під `api/v1/` з явними camelCase-маршрутами.
